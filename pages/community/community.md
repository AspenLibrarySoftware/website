## Aspen Open Source Community

Aspen is made for libraries by libraries. Anyone using Aspen, or interested in learning more about Aspen, is welcome to participate. [Community Gathering](https://drive.google.com/drive/folders/1IOuRZ0gsi2WwfhVURv04x8eFoy2NQds0){:target="_blank" title="Community Gathering folder on Google Drive"} is the monthly, all-hands-on-deck meeting.

Use the [Community Calendar](/calendar.html){:title="Community Calendar page"} to copy any meeting to your own calendar and/or view meeting details.

All agendas and notes can be found in the Aspen Community Shared Partner Folder.  The Aspen source code can be found at Github. We use Jira to coordinate work on the project.  Aspen documentation can be found on Confluence.
